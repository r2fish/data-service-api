## 5. 運用上の教訓

- ラベルを除くときは 3 つを見る: 同じ塊に残る文がそのラベルの名指す設計・WP に寄りかかっていないか、後ろの文が前に残ったラベルの段落の続きに読めないか、ラベルの中に内容語が無いか。検査器はどれも通す (来歴設計 §10.9・§10.10)。
- 位置参照を引き直す道具は、同じ行の直前のパスを継ぐ続きの形 (`` `:N` ``) も拾い、spec を当て直した後の再実行で止まらない形にする。設計レビューと再確認でそれぞれ 1 回ずつ欠陥が見つかった。
- CH-ID と `security/CONTROL_MAPPING.md` の版は、着手時に各 worktree の未コミットの差分まで見て取る。レビューの前と統合の前にも `git log <基点>..main` を見る。
- 別チャットの完了ゲートが排他ロックを持つ間は REFUSED 75 が返る。迂回せず、ゲートを再試行の loop に入れて待った。
- subagent が利用上限 (HTTP 429) で途中終了した (実装担当 1 回、監査担当 1 回)。作業ツリーは壊れず、同じ agent への送信で再開できた。
