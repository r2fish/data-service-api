### 2.3 完了条件

`--check` の赤 (合成 fixture。各条件だけを破った fixture で終了 1、適合 fixture で終了 0):

2. 語彙外の値 (状態・規模・印が D-2 の集合の外)。
3. 閉止日が `YYYY-MM-DD` の暦日でない (例 `2026-02-30`)。
4. 字数超過 (件名 41 字、着手条件 61 字)。
5. 固定欄への `|` の混入。
6. ID の重複。
7. ID の欠番 (両表を合わせて 1..最大が連続でない)。
8. 表の中で ID が昇順でない。
9. 状態と表の不一致 (§8.1 に `閉止`、§8.2 に `未着手` 等)。

12. 記録ファイルの先頭 3 行のヘッダの欠落。
13. 空振り禁止: 行が 0 件なら赤。

`--open` / `--all` / `--show` / `--verify-move` / 終了コード:

14. `--open` の対象は `未着手` と `進行中` だけである (`常設` を含まない)。
15. `--open` の並びは印 `なし` が先、`あり` が後、その中は ID の昇順。
16. `--open` の末尾の集計行が `open=N (印なし=a 印あり=b; 未着手=c 進行中=d)` の形と値である。
17. `--format tsv` がタブ区切りで同じ行を出す。
18. `--all` が常設・閉止・却下を含む全行と状態ごとの件数を出す。
19. `--show R-N` が §8.1 の行、または記録ファイルの行とその節の追記行を出す。
20. `--verify-move`: 記録ファイルの行が基点の同じ ID の行と 1 字でも違えば赤。
21. `--verify-move`: §8.1 の行の「内容」「行き先」部分が基点の行の ID セルより後と 1 字でも違えば赤。
22. `--verify-move`: 基点の ID が記録ファイル + §8.1 に無ければ赤。基点に無い ID は件数だけ出し、赤にしない。
23. 前提エラー (ファイルが読めない、§8 が無い、git が使えない) は終了 78。
24. 実物の台帳で `--check` が緑 (WP-2 の後)。
