## 5. 運用上の教訓

- **閉止の直前に main を merge し、版を振り直す。** 並行チャットが台帳・`CM` の版と `COLLECTION_FLOOR` を動かすためである。本チャットでは 2 回やり直した。

- **`RM` §8.2 の索引は ID 昇順に並べる。** 崩すと `tools/dev/ledger.py --check` が赤にする。

- **英文の確定文を監督が組むときは、確定文ファイルを版管理する。** レビューと監査が文の過不足を見つけるからである (R-30 で v1 → v3)。
